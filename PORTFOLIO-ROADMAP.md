## Study protocol

Problem → prerequisite map → targeted reading → hand-worked example → implementation → validation → transfer exercise → technical note.

Each study should include a mathematical question, assumptions, references, reproducible instructions, baseline, tests and limitations. Record AI assistance and distinguish generated suggestions from independently checked results.
